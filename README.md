# Lab 2 - Persistance JPA & Hibernate

Projet de gestion de salles et d'utilisateurs utilisant JPA, Hibernate et une base de données H2 en mémoire.

## Structure du projet

- `com.example.jpa.entities` : Entités JPA (`Salle`, `Utilisateur`).
- `com.example.jpa.dao` : Couche d'accès aux données (DAO avec JPQL).
- `com.example.jpa.service` : Couche service et gestion des transactions.
- `com.example.jpa.test` : Tests unitaires JUnit.
